# 无人艇航向保持控制 —— 演示素材仓库

本仓库用于存放《控制理论方法 Agent》课程演示的图片与动画，供 Coze 智能体通过
GitHub raw 链接引用。

## 目录

- `images/`：全部演示素材（12 张 PNG + 7 个 GIF）

## Raw 链接格式

```
https://raw.githubusercontent.com/<你的GitHub用户名>/<仓库名>/main/images/<文件名>
```

例如（把用户名和仓库名替换成你自己的）：

```
https://raw.githubusercontent.com/yourname/heu-heading-assets/main/images/control_block_diagram.png
```
